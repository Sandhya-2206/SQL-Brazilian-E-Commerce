# 📊 Brazilian E-Commerce Data Analysis (SQL Project)

## 📌 Overview

This project analyzes a Brazilian e-commerce dataset to extract meaningful business insights related to customer behavior, sales trends, and regional performance. The analysis simulates real-world business scenarios and supports data-driven decision-making.

---

## 🛠️ Tools & Technologies

* SQL (Structured Query Language)
* Microsoft SQL Server (SSMS)
* Relational Database Concepts

---

## 📂 Dataset Description

The dataset consists of multiple related tables, including:

* Customers
* Orders
* Payments
* Geographic data (city & state)

These tables were combined using SQL queries for analysis.

---

## 🔍 Key Analysis Performed

* Total orders and unique customers analysis
* Year-wise order trends
* Top-performing cities and states
* Order status evaluation (delivered vs cancelled)
* Customer distribution across regions
* Payment behavior analysis (installments)
* Identification of high-demand regions

---

## 💡 Key Insights

* Certain regions generate higher sales
* Customer demand varies by location
* Payment patterns show customer preferences
* Order trends highlight growth opportunities

---

* Data filtering and exploration
* Business insight generation
